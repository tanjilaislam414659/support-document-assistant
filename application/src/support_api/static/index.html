How to read these findings
These saved Milestone 5 aggregates concern the frozen BM25 + Qwen3 experimental candidate. They do not measure this interface, API or ticket workflow. They do not establish trusted automatic-support or production readiness.
The pilot is small and its variants belong to related question families. Families are not independent large samples. The holdout is consumed; it was not rerun for this application.
T01 source-coverage caveat
The supplied activation table contains the requested fact, even though it fails the broader, frozen strict source-span coverage proxy. The primary retrieval and coverage scores remain unchanged. Presence of the fact and satisfaction of that proxy are different measurements.
What validation can and cannot tell you
Valid JSON means the output has a parseable structure. Application acceptance adds schema and eligible-citation checks. Neither proves factual correctness, completeness or citation support. An insufficient_evidence status can still contain an unsupported answer and fail successful abstention.
Local data and review
Drafts contain user statements, explicitly supplied environment details, quoted documentation and human notes. A review applies to one saved revision. Editing creates a new revision and invalidates its previous review. Review labels are not authenticated identities. There is no submission endpoint or command execution.
Platform and model limitations
The default workflow needs no model. Docker supports search, local drafts and review only; experimental generation is not packaged or supported on Linux. Native generation requires an explicit --experimental start and the existing pinned Windows CPU artifacts. It remains slow, unverified experimental output.
