# v0.2.0 — local support workflow

Application version 0.2.0 provides the model-free local workflow below. The owner approved publication and the MIT code license, copyright 2026 Tanjila Islam, on 2026-11-16. Third-party licenses remain separate.

- Same-origin responsive interface, pinned readable passages and selection.
- Editable deterministic SQLite drafts, revisions, stale-update rejection and explicit review events.
- Model-free Windows/Docker workflow with attributed immutable 40-parent corpus.
- Non-root/read-only container, loopback host exposure and persistent volume.
- Pinned CI workflow, synthetic integration checks and actual screenshots.
- Existing optional unverified Windows Qwen3 adapter; no weights/binaries.
- Curated saved evaluation evidence, failures and N/A fields.

Publication-only launcher changes use the unchanged bundle by default and a checkout-relative data directory. Original history is preserved. No research model/prompt/retrieval setting or final score changed.

Known limitations: ordinary correctness 3/6, abstention 0/4 and Recall@5 family macro2/3. Primary ordinary citation aggregates remain N/A. The visible holdout is consumed; families are small/related. T01's table contains the fact but fails a broader frozen span proxy; primary scores stay unchanged. Linux generation is unsupported; hosted Actions has passed the default integration workflow. Review is a local action, not authenticated identity or truth. No automatic-support readiness or general injection-resistance claim is made.

Verification: 12 API tests, 6 portable-corpus tests, 14 Chromium checks and 9 Docker/Compose checks passed in hosted CI. No real inference or benchmark question was run. See [workflow runs](https://github.com/tanjilaislam414659/support-document-assistant/actions/workflows/application.yml).
